柳江龙城行前准备

出发前，记住 3 件事

Before You Go
🚄 怎么去
  • 高铁：柳州站通达全国，南宁/桂林/北海转乘便利
  • 去三江：动车约1h，或自驾约2h
  • 市区柳江环绕，公交+打车；江景步道/游船体验柳江
📅 最佳季节
  • 春季3–5月花木繁盛、气温宜人
  • 秋季9–11月天高气爽，看江最佳
🏨 住哪
  • 近江景夜市选城中区/窑埠古镇
  • 交通方便选柳北区（近柳州北站）
TIP　螺蛳粉原产地吃最地道，辣度可自选；江景夜游提前查开船时间。

柳江龙城Day2 · 螺蛳粉
Day2 · 美食日
螺蛳粉故乡
老牌螺蛳粉店 → 柳州工业博物馆 → 返程
🍜 地道螺蛳粉
  • 酸辣鲜爽，汤底用螺蛳+猪骨熬制
  • 加料：腐竹、酸笋、花生、青菜、辣油
  • 深巷老字号多，本地人常排队
🏭 工业博物馆
  • 柳州是工业名城，博物馆记录城市双面
  • 吃完粉可顺路一逛，午后轻松
TIP　螺蛳粉辣度自选：微辣/中辣/加辣；酸笋是精华，怕冲味可少放。另有螺蛳鸭脚煲、螺蛳粉火锅、糖水、五色糯米饭。

动车/自驾赴三江 → 程阳风雨桥 → 侗寨鼓楼 → 百家宴
🌉 程阳八寨
  • 程阳风雨桥是世界廊桥建筑杰作、侗族核心地标
  • 侗寨鼓楼是侗族村寨中心，木构精美
  • 百家宴是侗族待客大餐，体验原汁民俗
🗺 顺游
  • 丹洲古镇为江心岛古镇，可顺游
  • 早起看晨寨，山里云雾缭绕
TIP　三江为少数民族聚居区，尊重当地民俗；山区天气多变，备薄外套。预留整天往返更从容。

柳江龙城柳江夜景

百里柳江 · 百里画廊

Night Cruise
🚢 柳江夜游
  • 乘船看两岸高楼灯光与跨江大桥（文惠桥/柳江大桥）
  • 华灯初上时江景最美，凉爽惬意
⛰ 登高观江
  • 蟠龙山/马鞍山登高看「三面柳江绕城」全景
  • 视野开阔，夜景尽收眼底
🏮 窑埠古镇
  • 仿古街区+灯光夜市，晚餐后散步
  • 周末节假日更热闹
TIP　江景最佳在傍晚-入夜；夜游提前查开船时间，旺季预留排队。
