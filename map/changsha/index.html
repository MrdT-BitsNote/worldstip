长沙 · 好友周末行行前准备

出发前，记住这 3 点

Before You Go
🏨 住哪最顺
  • 五一广场商圈：地铁 1·2 号线换乘，走路就能逛太平街、坡子街、黄兴路、IFS，首推
  • 想要江景可选湘江边酒店，离地铁稍远但晚上安静
  • 双人同住提前订周六晚，退房早备行李寄存
🚇 怎么走
  • 机场：黄花机场 → 磁浮快线/地铁 6 号线到市区，再换线
  • 高铁：长沙南站 → 地铁 2 号线直达五一广场
  • 市内以地铁 + 打车为主，1·2 号线几乎覆盖核心景点
🎒 必带
  • 充电宝（逛吃耗电）、晴雨伞（长沙爱下雨）、舒适的鞋
  • 身份证、少量现金；晚上外出两人一双

周五晚
Day 1 · 安顿下来
高铁 / 机场 → 地铁 1·2 号线 → 入住五一广场 → 太平街宵夜
🌃 首夜怎么过
  • 放好行李，去太平老街走走——古街 + 小店，晚上氛围好
  • 顺手第一杯茶颜悦色，加一份黑色经典臭豆腐打底
🛏 入住提醒
  • 周五晚到，早点休息，给周六存体力
  • 想直接晚场体验，可去超级文和友（复古龙虾馆，出片好拍）
TIP　太平街离酒店都近，轻装上阵，别把第一天就逛累。

周六·上午
橘子洲 · 岳麓山
橘子洲（小火车）→ 岳麓山 · 岳麓书院
🏞 橘子洲头
  • 地铁 2 号线橘子洲站直达，坐景区小火车看青年毛爷爷雕像与江景
  • 免门票需预约，观光小火车往返40元；靠江边吹风很舒服
⛰ 岳麓山 · 岳麓书院
  • 南门进（湖南大学站）看岳麓书院，山腰有爱晚亭
  • 时间紧就选其一：爱拍照去书院，想散步就上山
TIP　上午别排太满，留点腿力给下午逛街；岳麓书院40元·需官方实名预约（提前4天）。

长沙 · 好友周末行周六下午 · 逛街主场
周六·下午
逛到走不动为止
黄兴路步行街 → 坡子街正餐 → IFS 国金（可选乐园）
🛍 黄兴路 · 坡子街
  • 市中心第一步行街，店铺、小吃、潮牌扎堆，顺路打卡超级文和友
  • 坡子街吃湘菜：剁椒鱼头 · 辣椒炒肉 · 小炒黄牛肉，挑家排队短的
☁ IFS 国金中心
  • 顶楼 KAWS 雕塑打卡，商场里品牌逛街 + 拍照，天气再热也凉快
🔄 爱玩派二选一
  • 想玩项目可全下午改去长沙世界之窗等（见乐园卡）
  • 逛街与乐园二选一，别硬塞，省着腿力逛到晚上

周六·夜
解放西路 · 湘江夜景
黄兴路 → 解放西酒吧街 → 湘江 / 杜甫江阁
🌃 解放西路
  • 长沙「夜生活名片」，酒吧、Livehouse、KTV 扎堆，热闹到凌晨
  • 霓虹街景很出片，沿街走一圈氛围拉满
🍸 今晚这样选
  • 想安稳聊天 → 清吧/精酿吧（见酒吧卡）
  • 想热闹音乐 → Livehouse / 大电音现场
  • 想看江景 → 杜甫江阁附近沿江散步，更安全的夜
TIP　结伴打车回酒店，别单独走夜路；第二天不赶时间可多留一会。

周日上午
从容返程
自然醒 → 湖南博物院 → 米粉街嗦粉 → 返程
🏛 湖南博物院
  • 马王堆汉墓 · 辛追夫人、素纱襌衣，周一闭馆、务必提前预约
  • 值得预留 1.5–2 小时，人多早到
🍜 顺路嗦粉
  • 安排之前先去湖南米粉街吃碗原汤肉丝粉，长沙人的仪式感
  • 行李多先寄存，轻装去博物院和米粉街
🚄 返程小抄
  • 高铁在长沙南站（地铁 2 号线直达），提前 1.5–2 小时出发
  • 周末易堵，别卡点到站
TIP　博物院若约不上，可换岳麓山/IFS补个半天，不为此打乱节奏。

看清这些，玩得更安心

Stay Safe
🎒
防扒
人多的步行街、地铁里，双肩包背前面，手机不随手放口袋
🚕
打车
用正规平台，上车核车牌，深夜实时分享行程给好友

酒吧
只去正规店，不接陌生人递的酒，饮品不离视线，微醺即止
👭
结伴
夜间两人同行、少走暗巷，回酒店报平安
🚇
地铁换乘
五一广场是 1·2 号线换乘点，看准线路方向，别坐反
