核心打卡点

Must See
📍 古城必访
  • 虹桥风雨楼 — 地标，二楼观夜景/全景黄金机位
  • 北门跳岩 — 清晨晨雾机位，石墩踏过沱江
  • 沈从文 / 熊希龄故居 — 《边城》诞生地
  • 万名塔 / 雪桥 — 夜景倒影绝美，人少出片
  • 南华山 / 东门城楼 — 登高俯瞰整座古城
🎫 古城街区免费；九景联票约148元（学生半价）
北门跳岩 · 晨雾
TIP　看雾看夜景掐好时间点，是最值得留的原因。

苗寨体验

Miao Village
📍 推荐苗寨
  • 山江苗寨 — 周边经典苗族村寨，民俗氛围浓
  • 老洞苗寨 — 可选银饰/蜡染非遗体验
  • 德夯 / 边城 — 三日版可串芙蓉镇或矮寨大桥线
🎎 体验清单
  • 拦门酒 + 苗族歌舞表演
  • 苗服租赁拍照（古城内约50元更省事）
  • 银饰锻制 / 蜡染手作（非遗工坊）
苗族银饰 · 刺绣
TIP　苗服拍照古城内就能体验，不必专门进寨；进寨多为拼车/包车+门票，提前问清。
