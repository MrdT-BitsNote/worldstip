沈阳行前准备

出发前，记住 3 件事

Before You Go
🚄 怎么去 · 住哪
  • 高铁：沈阳站/沈阳北站，京哈线枢纽，交通极便
  • 市内：地铁 + 公交覆盖故宫、中街、北陵
  • 宿中街/故宫附近，吃逛便利，首推
🎒 必带
  • 故宫/帅府周一闭馆注意安排
  • 东北冬季寒冷，10月后必带保暖
  • 备好身份证与预约凭证

Day1 · 上午
沈故宫 · 盛京第一殿
大清门 → 崇政殿 → 凤凰楼 → 大政殿
🏯 看点
  • 清代满洲宫殿，世界文化遗产
  • 红墙金瓦，满族建筑与清史故事
  • 登凤凰楼看盛京街景
💡 游法
  • 故宫不大，2-3 小时足够
  • 上午人相对少，先看核心殿宇
TIP　沈阳故宫约 60 元，可买联票含帅府更划算。

帅府 · 中街
张氏帅府 → 中街 → 方城夜市
🏛 帅府看点
  • 张氏帅府，张作霖、张学良故居

  • 方城夜市烟火气足，适合晚餐
