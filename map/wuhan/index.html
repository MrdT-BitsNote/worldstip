武汉 · 好友周末行行前准备

出发前，记住这 3 点

Before You Go
🏨 住哪最顺
  • 武昌·楚河汉街商圈：地铁 2·4 号线交汇，逛街、过早都顺，首推
  • 汉口·江汉路商圈：老城区氛围浓，近江滩酒吧街
  • 闺蜜同住选双床房，提前订周六晚，退房早备行李寄存
🚇 怎么走
  • 机场：天河机场 → 地铁 2 号线直达市区
  • 高铁：武汉站/汉口站/武昌站 — 看买到哪站，就近安排
  • 市内以地铁+打车为主，2 号线可过江
🎒 必带
  • 充电宝（逛街耗电）、晴雨伞、舒适的鞋
  • 身份证、少量现金；晚上外出两人一双

周六·上午
过早一份，元气一天
粮道街过早 → 昙华林拍照 → 午餐湖北菜
🍜 过早吃什么
  • 热干面、三鲜豆皮、蛋酒——武汉早餐三件套
  • 粮道街老字号多，路边小店最地道，避开高峰排长队
📷 昙华林拍照
  • 红瓦老城 + 文艺咖啡店背景墙，轻松出片
  • 顺带在咖啡店歇个脚、补补电
TIP　上午别排太满，留点腿力给下午逛街。

武汉 · 好友周末行周六下午 · 逛街主场
周六·下午
逛到走不动为止
楚河汉街 → 武商梦时代 →（可选）武汉欢乐谷
🛍 楚河汉街
  • 中国最长的水岸步行街，品牌、美食、影院一站式
  • 沿街逛，累了找家店坐下来喝一杯
🏬 武商梦时代
  • 巨型室内购物中心，逛街、拍照、吃饭全覆盖，不怕下雨
🔄 爱玩派二选一
  • 想玩项目可全下午改去武汉欢乐谷（过山车等，见乐园卡）
  • 逛街与乐园二选一，别硬塞，省着腿力逛到晚上

武汉 · 好友周末行周六夜 · 过江微醺
周六·夜
江汉路 · 黎黄陂路 · 酒吧
2 号线过江 → 江汉路 → 黎黄陂路 → 酒吧 → 江滩
🌃 江汉路步行街
  • 「天下第一街」，欧式老建筑 + 繁华店铺，夜景灯带很出片
🏛 黎黄陂路
  • 老洋房街区，咖啡与胡同小酒馆扎堆，最文艺的夜
🍸 今晚这样选
  • 想安稳聊天 → 黎黄陂路清吧（见酒吧卡）
  • 想热闹音乐 → 楚河汉街音乐酒吧（RE-MIX 等）
TIP　结伴打车回酒店，别单独走夜路；第二天不赶时间可多留一会。

  • 睡到自然醒，就近过早，回血再出发
