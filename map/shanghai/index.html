Before You Go
🚇 怎么走
  • 机场：浦东 / 虹桥，机场地铁可直达市区
  • 市内：地铁网络发达，几乎覆盖所有景点，首选地铁
  • 高峰期打车易堵，地铁+步行最顺畅
🏨 住哪
  • 宿人民广场 / 南京东路 / 外滩一带：逛吃方便，首推
  • 想去迪士尼，可宿迪士尼周边/度假区更近
🎒 必带
  • 身份证（购票/住宿）、地铁 app、移动电源
  • 看实景看剧（如迪士尼）备好票；冬夏备会极端外衣

上海Day1 · 外滩 · 陆家嘴
都市
一江两岸 · 魔都天际线
陆家嘴 → 过江（隧道/轮渡）→ 外滩 → 南京路
🏙 看点
  • 陆家嘴：东方明珠、金茂/环球/上海中心，三件套打卡
  • 外滩：万国建筑博览群，黄浦江畔看对岸天际线
  • 入夜江面霓虹亮起，夜景必看
💡 玩法
  • 下午登高楼观景或逛正大，黄昏后到外滩看华灯
  • 可乘观光江轮 / 2 元过江轮渡体验
TIP　外滩游人多，早点去或错峰；夜景以「亮灯后」为佳。南京路步行街顺逛。

上海Day2 · 豫园 · 老城厢
老城
江南园林 · 城隍烟火
豫园 → 城隍庙 → 梧桐街巷
🏮 看点
  • 豫园：江南古典园林，奇石假山、亭台水榭
  • 城隍庙商圈：寺庙烟火 + 小吃老街，热闹有年味
🍜 吃
  • 南翔小笼、鲜肉月饼、梨膏糖等在此尝鲜
  • 消费、人流都偏高，早去错峰更舒服
TIP　豫园门票约 40 元。老城厢人多，逛完步往武康路（下卡）切换法式悠闲。

上海Day2 · 武康路 · 梧桐
漫步
梧桐街巷 · 法式洋房
武康大楼 → 武康路 → 沿街咖啡馆 / 小店
🍁 看点
  • 武康大楼地标打卡，梧桐树影与老洋房
  • 武康路、安福路一带，法式街巷咖啡馆、买手店
  • 慢走慢逛，是「city walk」的上海样本
💡 玩法
  • 午后阳光+树影最出片，穿舒适鞋走街
  • 路边咖啡馆歇脚，慢品魔都悠闲
TIP　武康路一带免费漫步。避开正午暴晒，选下午光线更好。

上海Day3 · 上海迪士尼
乐园
梦想照进现实 · 全天主题
入园 → 热门项目 → 巡游/演出 → 烟花秀
🎢 看点
  • 七大主题园区，明星项目如飞跃地平线、创极速光轮等
  • 花车巡游、晚间烟花秀不容错过
  • 亲子 / 大小朋友皆可，童话氛围拉满
💡 攻略
  • 提前下载官方 App 看排队、约热门项目
  • 门票较贵、人潮大，提前订票、早起入园
  • 带好身份证明，水和零食有规定请先查
TIP　迪士尼建议单独安排一天；App 排队+演出一并规划，别错过烟花散场、留足出园时间。
